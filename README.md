# Personal Blog Portfolio - CSD 34203

## Deskripsi Projek
Projek ini merupakan sebuah laman web Blog Peribadi yang berfungsi sebagai portfolio digital bagi kursus **CSD 34203 Special Topics in Software Development** di UniSZA. Laman web ini mempamerkan biodata, kemahiran pembangunan perisian, serta beberapa artikel penulisan ringkas.

## Ciri-ciri Utama (Features)
* Laman Utama (Home Page) dengan mesej alu-aluan.
* Halaman Mengenai Diri (About Page) yang menerangkan latar belakang akademik.
* Halaman Blog (Blog Page) mengandungi 3 contoh artikel perkongsian.
* Halaman Hubungi (Contact Page) dengan maklumat emel dan media sosial.

## Teknologi yang Digunakan
* HTML5 (Struktur web)
* CSS3 (Gaya reka bentuk & susun atur)

## Cara Menjalankan Projek
1. Muat turun (clone) repositori ini ke komputer anda.
2. Buka fail `index.html` menggunakan mana-mana pelayar internet (Chrome, Edge, Firefox).
