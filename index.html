Blog & Insights

Project 1: 3D Animation A Simple Cleaning Routine

This project focuses on creating a 3D animation that demonstrates a simple daily cleaning routine. The animation was developed by applying concepts of 3D modelling, character movement, scene composition, and animation techniques to create a smooth and engaging visual presentation. This project helped enhance creativity and technical skills in producing interactive digital media content.

Project 2: RM Sehari 2026

RM Sehari 2026 is a project developed to promote awareness of budget management and encourage users to practice smart financial planning in daily life. The project aims to provide users with an easier way to monitor and manage their daily expenses through a simple and user-friendly interface.

Project 3: Essence of Elegant (Perfume Paradise & De’Vogue)

Essence of Elegant is a digital project developed for perfume-related businesses, Perfume Paradise and De’Vogue. The project focuses on creating an attractive and modern platform to showcase products, enhance user experience, and strengthen brand identity through creative design and interactive features. It combines elements of web design, user interface design, and digital media presentation.
